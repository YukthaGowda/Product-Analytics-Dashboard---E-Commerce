# Customer Churn Analysis & Product Analytics Dashboard

## 📌 Overview
This project analyzes customer behavior to identify key drivers of churn and improve retention strategies using data-driven insights.

## 🎯 Objective
- Understand why customers churn
- Segment users based on behavior
- Identify at-risk customers
- Provide actionable business recommendations

## 🛠 Tools & Technologies
- Python (Pandas, Matplotlib)
- Jupyter Notebook
- Power BI
- SQL

## 📊 Key Analysis
- Exploratory Data Analysis (EDA)
- Customer Segmentation (Low, Medium, High Value)
- Churn Analysis
- At-Risk Customer Identification

## 🔍 Key Insights
- High cart abandonment strongly correlates with churn
- Low engagement users are more likely to churn
- High-value customers are retained better
- At-risk users show significantly higher churn rates

## 💡 Business Recommendations
- Improve checkout experience to reduce cart abandonment
- Target low-engagement users with retention campaigns
- Focus on converting medium-value users to high-value
- Implement personalized offers for at-risk users
